# เกิดใหม่ในไทย — MVP 0.2 (กิจกรรม / โฟกัสชีวิต / ความสัมพันธ์)

โปรเจกต์ต้นแบบเว็บจำลองชีวิตตั้งแต่เกิดจนเสียชีวิตในประเทศไทย ภาษาไทย ใช้งานออฟไลน์ได้ (ไม่ต้องต่อ AI API)

## ทดลองเล่น

- เปิด `index.html` ในเบราว์เซอร์ (ทำงานเป็น static HTML/JS)
- หรือเปิดไฟล์ `koet-mai-thai-v02-demo.html` ซึ่งรวมทุกไฟล์เป็นหน้าเดียว (แนบแยกจาก ZIP)
- จำเป็นต้องเลือกปีเกิด **พ.ศ. 2493–2569** ก่อนเริ่ม
- จังหวัดเกิด 77 จังหวัดถูกสุ่มโดยให้น้ำหนักเท่ากัน **ในรุ่นทดลอง** ไม่ใช่ตัวเลขการเกิดจริง
- เมื่ออายุเพิ่ม: **ปีปฏิทิน = ปีเกิด + อายุ** เหตุการณ์ประวัติศาสตร์ที่ตรวจสอบได้จะแสดงในปีจริง ส่วนเหตุการณ์ชีวิตเป็นเรื่องจำลอง
- ชีวิตยังจำลองต่อหลัง พ.ศ. 2569 จนกว่าตัวละครเสียชีวิตตามความเสี่ยงตัวอย่างที่เปลี่ยนตามอายุ (เพดานทางเทคนิค 120 ปี)

## สิ่งใหม่ v0.2

1. **สุ่มกิจกรรมให้เลือกทุกปีตั้งแต่อายุ 6–18 ปี** มีทั้งเรื่องเรียน งานกลุ่ม ชมรม กีฬา ค่าขนม การสอบ ชุมชน ความคาดหวังที่บ้าน เพื่อน และความรักวัยรุ่น โดยกิจกรรมหลักและกิจกรรมสุ่มอาจเกิดปีเดียวกันได้
2. **โฟกัสชีวิต** เลือกได้จาก 5–7 หมวดตามช่วงอายุ เช่น การเรียนรู้ กีฬา เพื่อน ครอบครัว งานอดิเรก ความรัก อาชีพ การเงิน และสุขภาพ
   - โฟกัสเลือก/เปลี่ยนได้ขณะเล่น; ผลต่อค่าสถานะและความสัมพันธ์ถูกคำนวณ **เพียงครั้งต่อหนึ่งปีที่จำลอง** ไม่ใช่ทุกครั้งที่กดเลือก
   - กิจกรรมที่สุ่มมาได้รับน้ำหนักเพิ่มตามโฟกัส และมีระบบหลีกเลี่ยงการสุ่มรายการซ้ำติดกัน
3. **ความสัมพันธ์ระยะยาว** มีความสนิทกับครอบครัว (และผู้ดูแลหลักในวัยเด็ก), เพื่อนสนิทที่มีชื่อ, คนรักที่มีชื่อ/สถานะคบหา/คู่ชีวิต, การแยกทาง และสมาชิกใหม่ของครอบครัว
4. **ใช้เวลาร่วมกัน 1 ครั้งต่อปี** เลือกกิจกรรมกับครอบครัว เพื่อน หรือความรักได้ด้วยตัวเอง ช่วยพัฒนาความผูกพัน บางผลลัพธ์มีความไม่แน่นอน
5. **กิจกรรมต่อวัยผู้ใหญ่และวัยสูงอายุ** สุ่มเป็นระยะ ไม่ต้องตอบคำถามทุกปี และยังมีจุดเปลี่ยนจาก v0.1 (เพิ่มอายุ 4 และ 12 ปี)
6. **ข้าม 10 ปี (สุ่มคำตอบ)** กดเพื่อให้ระบบตอบกิจกรรมระหว่างปีที่ข้ามตาม seed ของชีวิต; เล่นปีต่อปีจะหยุดเพื่อให้เลือกเอง
7. **บันทึกผลลัพธ์ทันที** ในการ์ดเรื่องราวและไทม์ไลน์ มีสรุปโฟกัสที่ทำต่อเนื่องและความสัมพันธ์ตอนสิ้นชีวิต
8. **ความสมเหตุสมผลของยุค** บางกิจกรรมมี `sinceBE` เช่น เนื้อหาออนไลน์ไม่ปรากฏก่อน พ.ศ. 2556 และชุดกิจกรรมที่อาศัยการอยู่ในโรงเรียนถูกกรองในเส้นทางที่ออกจากโรงเรียนแล้ว

## โครงสร้าง

```
index.html          หน้า UI
assets/style.css    รูปแบบ responsive
assets/data.js      จังหวัด / สังกัดจังหวัดตามยุค / เหตุการณ์ประวัติศาสตร์ที่มีแหล่งอ้างอิง / milestone
assets/events.js    กิจกรรมชีวิตจำลอง + ตัวเลือกโฟกัส + เงื่อนไขความสัมพันธ์
assets/sim.js       random seeded simulation / focus / people / choice queue / life state
README.md           เอกสารนี้
test_mvp.js         regression test ด้วย Node.js (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
```

รันทดสอบ `node test_mvp.js` (ทดสอบปีเกิด, ประวัติศาสตร์ พ.ศ. 2540, กิจกรรมทุกปีอายุ 6–18, โฟกัส, ความสัมพันธ์, อัตโนมัติ, อนาคต, การเสียชีวิต และปีของเทคโนโลยี)

## ข้อจำกัดที่ต้องทราบ

- **ยังไม่ใช่แบบจำลองที่ผ่านการปรับเทียบกับสถิติประชากรไทยจริง:** คะแนน เงินเดือน ความมั่งคั่ง โอกาสคบหา การมีลูก กิจกรรมที่เกิด ความสำเร็จ และความเสี่ยงเสียชีวิตเป็นเพียงสมมติฐานประกอบการทดลองระบบ
- เหตุการณ์ประวัติศาสตร์ที่ใส่ใน v0.2 ยังมีแค่ตัวอย่างสี่เหตุการณ์ (2540, 2547, 2554, 2563); ข้อมูลประวัติศาสตร์ยังไม่ครอบคลุมทุกปี และเหตุการณ์บางอย่างมีเงื่อนไขจังหวัด
- **กิจกรรมชีวิตและผลกระทบส่วนตัวทั้งหมดเป็นเรื่องสมมติ** ไม่ใช่การยืนยันว่าเหตุการณ์นั้นเกิดกับคนใดจริง
- มีการกรองกิจกรรมออนไลน์และกิจกรรมที่ต้องอยู่ในโรงเรียนเบื้องต้น แต่การเรียน ค่าเงิน วิถีชีวิต และโอกาสระดับจังหวัดตามยุค **ยังไม่ได้เทียบข้อมูลย้อนหลัง**
- จังหวัดยังสุ่มเท่ากันทั้ง 77 จังหวัด; การแสดงชื่อจังหวัดประวัติศาสตร์จัดการพื้นที่ที่แยกจังหวัดจากยุคเดิมเพื่อไม่ให้ใช้ชื่อที่ยังไม่ก่อตั้ง
- เป็นเกมภายในเบราว์เซอร์ ข้อมูลชีวิตบันทึกใน localStorage ของอุปกรณ์นั้น ไม่ส่งไปยังเซิร์ฟเวอร์ และไม่ใช่แหล่งข้อมูลการแพทย์/พยากรณ์รายบุคคล
- เซฟรุ่น v0.1 และ v0.2 แยกจากกัน เพื่อไม่ให้โครงสร้างสถานะใหม่ทำให้เซฟเดิมเสียหาย
- ยังไม่มี AI ที่เรียกใช้งานระหว่างเล่น ควรเพิ่ม AI เพื่อเรียบเรียงข้อความเท่านั้น หลังย้ายการคำนวณไปยัง simulation engine ที่ตรวจสอบได้
